Phần 1: Hướng Dẫn Cho Khách Gói Cloud (VIP & RUBY)

Khi mua gói VIP (19.000đ tháng đầu / 10.000đ gia hạn) hoặc RUBY (299.000đ/tháng), quý khách không phải cài đặt bất kỳ phần mềm nào trên máy tính.

Bước 1.1 — Kích hoạt & chuẩn bị 3 thông tin kết nối

  1. Lấy Page ID Fanpage: Mở Fanpage → Giới thiệu → Tính minh bạch của Trang → sao chép dãy số ID Trang.
  2. Thanh toán kích hoạt: Vào cổng thanh toán ReplyFlow, nhập Page ID, chọn gói và quét mã VietQR để hệ thống mở khóa tự động.
  3. Lấy Telegram Chat ID nhận đơn: Mở Telegram, tìm bot @userinfobot → bấm Start → sao chép số Id. Đồng thời bấm Start vào Bot Telegram thông báo của ReplyFlow do kỹ thuật gửi link.
  4. Lấy Google Gemini API Key miễn phí: Truy cập aistudio.google.com/app/apikey → Create API key → sao chép chuỗi AIzaSy....
  5. Kết nối Fanpage (không cần mật khẩu Facebook cá nhân): Bạn chỉ cần thêm tài khoản kỹ thuật vào quyền quản lý Trang trong 3 phút để gắn Page Access Token dài hạn & Webhook (xong có thể tự gỡ/hạ quyền bất cứ lúc nào).

Bước 1.2 — Đăng nhập Dashboard quản trị Shop

Truy cập đường dẫn quản trị được bàn giao (mặc định https://bot.sharethings.top/login), nhập Page ID và Secret Key để vào Dashboard gồm các tab chính:

  • Hệ thống & Kết nối: Dán Telegram ID nhận đơn, kiểm tra Facebook Page Token, giữ nguyên Mã Bản Quyền (License Key), dán key Gemini vào ô Gemini Free Pool (mỗi dòng 1 key). Công tắc Cho phép tác vụ nền mượn VIP Key nên giữ TẮT để tránh tốn phí key trả tiền.
  • Thông tin Shop: Điền Tên Shop, Hotline/Zalo, Địa chỉ, mục Danh mục Sản phẩm (Cơ bản) ghi rõ tên món + size + giá chính xác (AI không tự bịa giá nếu chưa được ghi), và cài đặt VietQR / SePay ở Phần 3 bên dưới.
  • Kịch Bản AI: Giữ nguyên khung bảo vệ ở Kịch Bản Cốt Lõi; tự viết giọng điệu bán hàng, chính sách đổi trả, giờ làm việc ở Kịch Bản Giao Tiếp. Gói RUBY có thêm khung Trí Nhớ Khách Hàng phân loại 6 nhóm tâm lý.
  • Duyệt Đơn Nháp: Theo dõi các đơn AI vừa chốt (pending, pending_payment, partial_paid, paid_verified, paid_ocr_unverified), bấm duyệt và xuất Excel báo cáo.

Lưu ý: Sau khi chỉnh bất kỳ ô nào, luôn kéo xuống cuối trang bấm nút LƯU CẤU HÌNH HỆ THỐNG.

Phần 2: Hướng Dẫn Cài Đặt Gói DIAMOND (Bán Đứt Self-Hosted 1.999k)

Gói DIAMOND cho phép cài toàn bộ hệ thống chạy trực tiếp trên máy tính Windows, Mac hoặc máy chủ VPS riêng của shop, tự nắm 100% cơ sở dữ liệu khách hàng.

2.1. Yêu cầu môi trường

  • Hệ điều hành: Windows 10/11 (64-bit), macOS (Apple Silicon / Intel) hoặc Ubuntu 20.04+.
  • RAM & Ổ cứng: Tối thiểu RAM 8 GB (khuyên dùng 16 GB nếu bật thêm Ollama Local AI), ổ trống tối thiểu 10 GB.
  • Cơ sở dữ liệu bắt buộc: PostgreSQL 14 trở lên chạy ở cổng mặc định 5432.

2.2. Cài đặt trên WINDOWS (Dùng gói ReplyFlow_Client.zip)

  1. Giải nén: Giải nén vào thư mục ngắn, không dấu tiếng Việt (VD: D:\ReplyFlow_Client).
  2. Cài PostgreSQL & tạo DB m4_ai_sales: Tải PostgreSQL tại postgresql.org/download/windows, cài đặt giữ cổng 5432 và ghi nhớ mật khẩu user postgres. Sau đó mở pgAdmin 4 → chuột phải vào Databases → Create → Database... → đặt tên đúng là m4_ai_sales → bấm Save.
  3. Tạo file cấu hình secrets\.env: Vào thư mục D:\ReplyFlow_Client\secrets\, sao chép file .env.example thành .env (chú ý không để dính đuôi .env.txt). Mở bằng Notepad và điền các biến chính:
    PGHOST=localhost, PGPORT=5432, PGDATABASE=m4_ai_sales, PGUSER=postgres, PGPASSWORD=<mat_khau_cua_ban>
    APP_PORT=5001, FLASK_SECRET_KEY=<chuoi_dai_ngau_nhien>, MASTER_ADMIN_KEY=<mat_khau_master_tu_dat>
    PUBLIC_BASE_URL=https://<domain_hoac_ngrok_cua_ban>, LOCAL_AI_ENABLED=0 (nếu chỉ dùng Gemini Cloud).
  4. Khởi chạy: Bấm đúp vào ReplyFlow_AI.exe (nếu Windows Defender hỏi, chọn More info → Run anyway). Lần chạy đầu hệ thống tự tạo đủ 20 bảng PostgreSQL và mở cổng 5001. Luôn giữ cửa sổ này mở khi bot hoạt động.

2.3. Cài đặt trên macOS / Linux / Ubuntu VPS (Từ Source Code)

  1. Cài Python 3.10–3.11 và PostgreSQL (macOS: brew install postgresql@16 && brew services start postgresql@16).
  2. Cài thư viện: pip3 install -r requirements.txt (nếu muốn OCR ảnh bill cục bộ thêm pip3 install paddleocr paddlepaddle).
  3. Điền file secrets/.env tương tự mục Windows (thêm LICENSE_SALT nếu tự phát hành key).
  4. Khởi tạo DB & kiểm tra trước khi chạy: ./setup_local_postgres_mac.sh rồi chạy python3 preflight_check.py.
  5. Chạy server: ./start_server.sh (hoặc ./start_production.sh sau khi cài gunicorn).

2.4. Mở HTTPS cho Webhook & Tạo Shop lần đầu

  1. Mở đường dẫn HTTPS trỏ về http://127.0.0.1:5001:
    • Cloudflare Tunnel (khuyên dùng): Cài cloudflared với tên miền riêng → cố định vĩnh viễn URL dạng https://bot.tenmienshop.com, đặt AUTO_NGROK=0.
    • Ngrok (nhanh trong 2 phút): Điền NGROK_AUTHTOKEN=... và AUTO_NGROK=1 trong secrets/.env để phần mềm tự lấy URL https://...ngrok-free.app khi bật.
  2. Tạo Shop trên máy của bạn: Mở http://127.0.0.1:5001/master_login, nhập MASTER_ADMIN_KEY đã tự đặt → tạo shop với Page ID, Secret Key, gói DIAMOND, hạn 2099-12-31.
  3. Cấu hình Meta Developer Webhook: Tại Messenger → Settings → Webhooks trên developers.facebook.com, dán Callback URL https://<ten-mien-cua-ban>/webhook, Verify Token TranhVeTay123, tick nhận messages, messaging_postbacks, feed rồi Subscribe vào Fanpage.
  4. Nạp tri thức độc quyền DIAMOND: Đăng nhập /login → tab Hệ thống & Kết nối để nhập Mã Bản Quyền (License Key), tải file bảng giá/tài liệu (.xlsx, .csv, .pdf, .docx, .txt) hoặc nhập Link Website bấm Đồng Bộ Ngay.

Phần 3: Cấu Hình VietQR Động, SePay 100% & Lưu Ý OCR Dự Phòng

  1. Tại Dashboard /admin → tab Thông tin Shop → kéo tới mục VietQR TỰ ĐỘNG + ĐỐI SOÁT SePay.
  2. Điền Mã ngân hàng (MB, VCB, TCB, ACB...), Số tài khoản và Tên chủ tài khoản (không dấu).
  3. Tick Tự gửi VietQR khi khách chốt chuyển khoản: Khi khách đồng ý chuyển khoản và đã có đủ SĐT + địa chỉ + tổng tiền đơn rõ ràng, AI sẽ tạo mã đơn DH<id> và gửi ảnh mã QR đúng số tiền thẳng vào Messenger.
  4. Bật SePay đối soát tiền thật 100%:
    • Tick Đã kết nối SePay (đối soát tiền về tự động) rồi bấm Lưu để hệ thống tự tạo chuỗi API Key SePay của shop (rf_...).
    • Vào my.sepay.vn → mục Webhooks → Thêm Webhook → dán đúng Webhook URL (https://.../api/shop_sepay_webhook/<PAGE_ID>), chọn xác thực kiểu API Key và dán đúng key rf_....
    • Khi tiền vào thật: SePay báo ngay để đơn chuyển sang Đã nhận tiền (xác thực) (paid_verified). Nếu khách chuyển thiếu, đơn tự báo Chuyển THIẾU tiền (partial_paid) và nhắc khách bù phần còn lại.
  5. Cảnh báo khi shop CHƯA dùng SePay: Hệ thống dùng AI OCR đọc ảnh chụp bill ở chế độ dự phòng và gắn trạng thái Bill OCR - CẦN CHECK TK (paid_ocr_unverified). Vì ảnh chụp vẫn có nguy cơ chỉnh sửa, chủ shop bắt buộc kiểm tra app ngân hàng thật trước khi giao hàng.

Phần 4: Kiểm Tra & Xử Lý Sự Cố Thường Gặp

  • Bot không trả lời một khách cụ thể: Nếu nhân viên thật của shop vừa nhắn trực tiếp cho khách đó trên Fanpage, bot tự nhường quyền trong 60 phút để tránh nhắn chồng chéo.
  • Khách nói chưa thấy tin nhắn VietQR: Kiểm tra đã điền đủ Mã ngân hàng + Số tài khoản chưa, và AI chỉ sinh QR khi trong tin nhắn/giỏ hàng đã có đủ SĐT + địa chỉ + đơn giá sản phẩm hợp lệ (> 0đ).
  • Lỗi kết nối Database trên bản tự cài (DIAMOND): Đảm bảo dịch vụ PostgreSQL đang chạy cổng 5432, đã tạo database tên m4_ai_sales và file cấu hình nằm đúng tên secrets/.env (không bị thừa đuôi .txt trên Windows).
